## Stalls found and fixed (root causes)

1. **enemy_scripted_hit 0x535F0 was a stub**: scripted enemies (guard actions) never lost life or died, so
   `enemies_alive` never fell (event 1 WAIT_ENALV). Ported, with enemy_scripted_dead 0x1C670 / _fall 0x1C780.
2. **enemy_wait_camera_stop 0x77350** (stub and unported routine): walkers never became attackers.
3. **body_free_parts cleared 0x51F7E8 instead of player_bodies 0x51F440** (src/game/enemy_support.cpp): dead
   humans stayed in player_bodies, hostage_list_humans gave event 3's guard a dead prey (the event-0 scientist), the
   held researcher was never linked to its captor, kept attack slot 2 and the camera never resumed.
4. **Molb groups (event 4) fell forever**: the floor modes molb_floor_stick / _bounce / _above, floor_probe,
   ground_height (coprocessor 0x62 ray test on the scene's floor quads) and obj_move_heading.
5. **kind 70 never landed**: jump_arc_* were stubs (jump_arc_step_b returned 0 forever).
6. **kind180_room_object_frame (L5, src/port/scene_objects.cpp) used event flags 0x83 / 0x84** instead of 3 / 4
   (0x51E943 / 0x51E944; checked in the arcade and PC disassembly): event 4's chandelier never fell, WAIT_ITEM 4
   stalled. Fixed for A and PC.
7. **task_create_child_alloc 0x15010 returned 0**: hostage_struck_mark's set-up wrote through address 0.
8. **Rain indoors** (user play-test): kind173_list_frame (L5) ended the rain at event flag 0x85 instead of 5 (0x51E945, A and PC); flag 5 is set in event 4.
9. **The guard cut the Chariot fight short** after 20 s (it counted per-frame system tasks as unported objects): those no longer count.

**User play-test (00:15, old main) "zombies stay alive, the ride gets stuck, the camera turns back to them":** there
is no separate off-screen despawn in the arcade route code: enemy_main (proven) removes an enemy only by death or
enemy_leave (flags bit 21 with route_choice 1); at camera stops the script waits on enemies_alive / enemy_count and
game_cam_stop_update looks at the attackers while attack positions 0-3 are held. On old main the scripted zombies
never died (1), never left wait-camera (2) and never released their slots (attack_slots_update stub), which kept the
camera looking back. All fixed on this branch (merged).
