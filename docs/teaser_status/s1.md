## Textures, palettes, sky (src/assets/arcade_loader.cpp, chapter.cpp)

- Without a texset file every stage's texture sets come from the ROM: the chapter's areas (table 0xAB0B0), then the
  other game areas (TEXCHG can load any: Chapter 1's boss room is area 4); the view draws with the area the game
  loaded last (as before).
- `buildTextureRam` now uploads as the program does: texture_ram_init (0xD40) block 0 into RAM 0, texture_area_upload
  (0xEB0) the area into RAM 1, both with their mip staircase alternating between the RAMs (rect_copy_512), then the
  area tiles. **Byte-exact** against MAME's texture RAM for every game area (all fullgame_us dumps sampled, areas 1, 3-12:
  0 differing words). The old approximate mip filter is gone (the mips are all in the ROM).
- Polygon palette from the ROM = MAME's at chapter load except the 30 animated entries (959, 984-1017, 1023);
  colour translation tables = MAME's at chapter load (0 of 24,576 differ). Later in the chapter the event scripts swap
  rows (color_row_set, rows 5-21: 915 entries differ at t02200): the old texset "rows" lines did this statically;
  now a runtime boundary (see open items).
- sky_task (0x33F50) ported in the runtime: the dome (table 0xAC1F0 by SKYTB's index, turning) and the cloud layer
  0x608, drawn as backgrounds. The old texset "sky" lines drew the clouds only; MAME shows the mountains too.
