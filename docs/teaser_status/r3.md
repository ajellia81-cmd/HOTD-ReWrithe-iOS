# R3 audio + HUD: status (2026-10-15)

Branch `claude/r3-audio-hud-0a5f15` (worktree `.claude/worktrees/r3-audio-hud-0a5f15`, build folder `build-r3`). Not

## Done
- **PC sound files decoded** (formats.md §30): GAMESNDS.RBH (214 sample entries of 40 bytes + 8-bit 11025 Hz bank),
  O_*.RBH (8-byte header + data), the full cue table (269 cues, types 0-5) in THOTD.EXE.
- **Mixer:** `game::Audio` (src/game/audio.*) on an SDL3 audio stream (44.1 kHz stereo float, 16 voices); bank
  samples, one-shots, stop cues, the "all off" commands, loops (loop start / flag).
- **Cue table:** arcade sound codes -> PC cues: `tools/cue_pairs.py` -> src/game/cue_map.inc (122 codes: 79 from
  routine pairs, 31 from the event scripts' SNDON aligned, music by rule). `sound_cue` / `sound_send3` go through it.
  Headless default route: 17 cue calls, all mapped (Chapter 1 music, boss music, thunder, voices) except 0xBE5000
  (a board setting).
- **Continue / game over:** mode 4 sub-modes 3 / 4 (shared countdown, 911 frames 9..0, trigger skips a digit), the
  per-player countdown, player states 4 / 6 / 9, mode 5 (game-over music, GAME OVER, then the chapter restarts).
  `--lives-kept` now defaults to 0; `--lives-out F` for testing. Headless: `hotd --frames 3000 --lives-out 600`.
- **HUD (placeholder) + crosshairs:** score, lives (torches), bullets, RELOAD!, CONTINUE? n, GAME OVER, PRESS START,
  per player at the bottom corners; red / blue crosshairs; F1 hides the developer lines. Screenshots include the HUD.

- **Sound not heard by me:** the device opens without errors and the cues fire; please listen once (`hotd.exe --root .`).
- HUD sprites: SPR.RBH = RBHH + BODY (1,640 u32 offsets, then 71 KB of sprite descriptors) + RELC; the pixels are
