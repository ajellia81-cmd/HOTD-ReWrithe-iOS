# The House of the Dead: ReWrithe v1.0.1

Bug-fix update for v1.0.0. Unzip it over your old folder (your settings are kept), or into a new one.

## Fixed
- **"155 of 156" PC files:** a patched THOTD.EXE (music fix, no-CD, Windows fixes) is now accepted. An **unpatched**
  1998 PC copy is still recommended. A backup of the original next to it (THOTD.EXE.orig or THOTD.EXE.bak) is used too.
- The setup now names the file that is missing or wrong (up to three; all of them in settings\hotd.log).
- The music count is its own line, marked optional: the CD music (Music\TrackNN.ogg) was never part of the check.
- Without the PC game's CD music the main menu plays the arcade's own song.

## New
- Video > Hit Sparks / Gun Muzzle Flash / Blood Particles: On/Off (for clean recordings).
- Gallery > Cut-scenes: the Hangedman's, the Hermit's and the Magician's defeats; Free Cam has a slow mode (C / Back),
  hotkeys 1 / 2 / 3 for the three switches above and H to hide the key hints; a scroll bar on the list.

Windows only for now: Linux / SteamOS and macOS builds are coming in an update.
Report bugs on the GitHub Issues page with settings\hotd.log (never attach game files or ROMs).
